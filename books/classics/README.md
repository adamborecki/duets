# Classics, One Hand Each

*Piano pieces by the masters shared between two players*

Each player takes one hand of the original: not a note is changed. Bach minuets, Schumann's Album for the Young, Burgmüller studies, Satie's Gymnopédies and more.

**67 duets.** Pick the edition that suits how you play:
